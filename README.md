# 📝 To-Do List App

A simple yet powerful To-Do List web application that helps users manage their daily tasks efficiently. This project is built using **HTML, CSS, and JavaScript** with dynamic DOM manipulation.

---

## 🚀 Live Demo

👉 https://ritesh-6022.github.io/todo-list-app/

---

## 📌 Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* ❌ Delete tasks
* ✔️ Mark tasks as completed
* ⌨️ Add task using Enter key
* 📱 Responsive design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (DOM Manipulation)

---

## 🧠 How It Works

* Users can enter tasks in the input field
* Tasks are dynamically added to the list using JavaScript
* Each task includes Edit and Delete options
* Clicking on a task marks it as completed
